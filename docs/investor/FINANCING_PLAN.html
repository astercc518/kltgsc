    ↓

4.2 三条核心获客链路

A. 竞品截流（实时）

Scout 进竞品群 → 监听新成员 → AI 评分 → Sniper 5 分钟内私聊
  → 用户回复 → AI 多轮洽谈 → 高意向告警 → 销售接管成交

B. 批量洗群（周度）

Scout 批量采集公海群成员（500-1000/群）→ AI 评分分层
  → A 层精准私聊 / B 层拉入养鱼群 / C 层丢弃
  → Actor 在养鱼群炒群造势 → 活跃用户 Sniper 收割

C. AI 客服 + 销售接管（核心闭环）

TG 私聊进入 → KB 检索（pgvector）→ 意图分析 → AI 回复
  → intent=purchase + is_high_value → WebSocket 高意向告警
  → 销售点击"接管" → Lead.ai_enabled=false
  → AI 切换副驾驶（不发送，只生成草稿 + 实时洽谈摘要）
  → 销售一键发送 / 改写 → 成交

七、技术壁垒与差异化 (Moat)

7.1 三大护城河

① 账号供给与养号工程化能力（最高门槛）

竞争对手最难复制的部分：
- 自动注册：SMS-Activate + IP2World + 设备指纹生成 → 单账号成本压到 ¥15
- 养号自动化：warmup_service 模拟真人行为 30-60 天
- 风控分级：cannon/scout/actor/sniper 4 角色 + 健康分 + 自动降级
- 失效补给：账号封禁后 1 小时内自动补号到客户池

② 1000+ 账号级真实工程能力

  • Listener 按 account.id % N 分片，5 分片支撑千账号长连接
  • Worker 多副本 + max-tasks-per-child=200 防 Pyrogram 内存泄漏
  • PG max_connections=500、Redis maxmemory=4G noeviction
  • 业内大多数群控工具止步于 50-200 账号

③ AI 副驾驶与销售协同的产品形态

  • 同行 A（纯群控）：只有"群发工具"，无 AI、无销售接管
  • 同行 B（AI 客服）：ChatGPT 套壳，无销售协同
  • TG1：AI 自动处理长尾流量 + 高意向自动告警 + AI 持续生成草稿/摘要给销售

7.2 商业模式的护城河

预养号资产是网络效应：
- 客户越多 → 账号池流转越快 → 单账号边际成本越低 → 定价更有优势
- 不同客户对账号要求差异化 → 平台可做"账号二级流转"（用过的 Cannon 降级再用）
